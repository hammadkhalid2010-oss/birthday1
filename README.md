# Birthday QR Website

A simple static website that creates a personalized **Happy Birthday** page and generates a QR code pointing to it.

## How it works

1. Open `index.html` on your hosted domain.
2. Enter the birthday person's name.
3. Click **Generate**.
4. Share the generated link or QR code.
5. When someone scans the QR code, they land on a personalized birthday greeting page.

## Local preview

```bash
python3 -m http.server 8000
```

Then visit: <http://localhost:8000>
